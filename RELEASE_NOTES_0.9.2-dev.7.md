# iDotMatrix WLED UserMod 0.9.2-dev.7

## Buzzer settings text cleanup

This build changes only the presentation text of the already-working Buzzer settings UI:

- removes the autogenerated `BuzzerActiveHigh` prefix so the line reads **Active buzzer active-high:**;
- removes the autogenerated `BuzzerPassiveTrigger` prefix so the line reads **Passive buzzer trigger:**;
- moves the saved-settings warning to the line below **Test buzzer**;
- changes the warning to **Save first: test uses saved settings.**

Conditional visibility is unchanged. Persistent configuration keys remain `buzzerType`, `buzzerActiveHigh`, and `buzzerPassiveTrigger`, with no migration.

The hardware-validated buzzer backend is unchanged: passive output remains 2 kHz LEDC with the existing 10-bit idle-duty handling, while active-buzzer behavior and Alarm / Program / Test timing are untouched.

## Clock presentation persistence

No change from the previous 0.9.2 development builds. Clock style, 12/24-hour mode, date visibility and RGB colour remain persisted in NVS and restored before standalone Clock fallback. The existing transient `showDate=0` protection remains unchanged. Device reset still clears the stored Clock presentation preferences.
